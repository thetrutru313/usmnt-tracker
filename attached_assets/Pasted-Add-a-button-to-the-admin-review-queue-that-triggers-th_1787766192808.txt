Add a button to the admin review queue that triggers the date-of-birth
backfill.

POST /admin/backfill-candidate-dob already exists (added in the eligibility
correctness fixes). It has no UI, and I can't call it from the browser console
because the app attaches its admin session in a way a raw fetch doesn't
reproduce. I need a button.

## What to add

In artifacts/usmnt-tracker/src/pages/AdminReviewQueue.tsx, add a "Backfill
Birth Dates" button next to the existing "Rescore All" button.

Match the existing button exactly in how it works — same auth path, same
mutation pattern, same loading and error handling, same styling conventions.
Do not invent a new fetch approach; copy whatever Rescore All already does so
the session is attached the same way.

Behaviour:

- Disabled while in flight, with a pending state on the label.
- On success, show the returned counts: updated, notFound, failed, total.
- On failure, surface the error rather than failing silently.
- Invalidate the same queries Rescore All invalidates, so the page refreshes
  after it completes.

The backfill makes up to three API-Football calls per candidate with no
birth date on file, so it can run for several minutes. Make sure the request
has no client-side timeout shorter than that, and that the pending state
persists for the whole run rather than resolving early.

candidate without one. May take several minutes and consumes API quota.
Continue?" I don't want to trigger it by a stray click.
