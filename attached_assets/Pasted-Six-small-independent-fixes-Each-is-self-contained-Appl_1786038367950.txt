FIX 7 — Make the frontend build work outside a Replit service.

Files: artifacts/usmnt-tracker/vite.config.ts lines 9-30
       artifacts/mockup-sandbox/vite.config.ts lines 8-22

Both configs throw if PORT or BASE_PATH is unset. This happens at
config-load time, during `vite build`, which starts no server and has no use
for a port. The result is that `pnpm run build` fails from any plain shell —
confirmed by execution. It works only inside a Replit service, where
artifact.toml injects the variables.

Replace the throws with defaults: PORT falls back to 5173 (usmnt-tracker) and
8081 (mockup-sandbox), BASE_PATH falls back to '/' and '/__mockup'
respectively. Keep reading the env vars when they ARE set — Replit must
continue to control them in the service context. Log which value was used at
config load so a surprising port is visible rather than silent.

Confirm `pnpm run build` now succeeds from a shell with no env vars set, and
that the Replit dev workflow still binds the injected port.
