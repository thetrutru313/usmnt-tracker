## Database structure recommendation

Instead of storing the provider on every match, normalize it:

```text
League
------
id
name
country
tier
streaming_provider_id

StreamingProvider
-----------------
id
name
app_store_url
website
logo

Match
-----
id
league_id
home_team
away_team
kickoff
```

That way, if a league changes from ESPN+ to another service, you update one record rather than every scheduled match.

For an app centered on USMNT players, this model scales well because you can simply associate each player with a club, each club with a league, and automatically inherit the correct streaming service.
