## Commit message

  fix(eligibility): detect national teams by team identity, not league name

  National-team detection matched league names against a keyword regex, so
  club competitions sharing those keywords — CONCACAF Champions League, FIFA
  Club World Cup — counted as national-team appearances with the player's
  club standing in for a country. Capped USMNT internationals including
  Arriola, Morris, and Delgado were flagged DUAL_NATIONAL as a result.

  - Add api_football_teams cache (id, name, country, is_national, fetched_at)
    populated once per team from /teams?id=, which returns an authoritative
    national boolean
  - Add isTeamNational() resolver: DB cache first, API on miss, never
    re-fetched. Fails closed on lookup failure and logs, rather than guessing
  - Gate detectSeniorNonUsCaps and countNationalTeamCaps on team identity;
    league-name matching is now only a cheap pre-filter and is never
    sufficient on its own
  - Retain a name-pattern backstop for youth national teams, which
    API-Football reports as national: false
  - Youth exclusion logic unchanged

  evaluateEligibility and its cap helpers are now async with an injectable
  resolver so tests can stub team identity.

  Dry run over currently-flagged candidates: 26 of 31 clear as false
  positives, 5 remain genuine dual nationals. No stored statuses changed —
  applied by rescore.

  Migration 0006 is DDL only. The cache seed for existing clubs is in
  lib/db/drizzle/backfill/ and is run by hand in production, since Publish
  carries the schema diff but not data.
